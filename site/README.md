# Stillpoint marketing site

A static landing page that points to the live app (https://stillpoint-recovery.vercel.app) and this GitHub repo. It is deployed as a separate Vercel project with Root Directory `site/`. There is no build step and it makes no third-party requests: fonts are self-hosted (OFL, see `fonts/`). Screenshots come from `pnpm screenshots` and the tour from `pnpm walkthrough` (sample data only); copy fresh ones from `docs/media/` when they change.
