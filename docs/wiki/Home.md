# Stillpoint Recovery Wiki

Stillpoint Recovery is a local-first, privacy-focused, faith-centered sobriety and recovery companion built as an installable React PWA.

## Start here

- [Getting Started](Getting-Started.md) — install, run, and build the app locally.
- [Architecture](Architecture.md) — understand the app shell, routes, domain layer, and IndexedDB boundary.
- [Data and Privacy](Data-and-Privacy.md) — learn what stays on-device, how backups work, and what is not promised.
- [PWA and Offline Behavior](PWA-and-Offline.md) — understand installation, caching, shortcuts, and network boundaries.
- [Testing and CI](Testing-and-CI.md) — run checks locally and understand the GitHub Actions workflow.
- [Content and Licensing](Content-and-Licensing.md) — distinguish MIT-covered source from bundled and linked content.
- [Contributing and Troubleshooting](Contributing-and-Troubleshooting.md) — make focused changes and diagnose common issues.

## Product principles

Stillpoint favors private-by-default behavior, reversible choices, gentle language, accessible interaction, and honest limitations. It does not require an account, cloud sync, analytics, advertising, or a recovery streak. It is not medical care, treatment, diagnosis, or an emergency service.

The public project README contains screenshots, motion previews, feature details, Mermaid diagrams, and the fastest local setup path.
